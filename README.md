# DrumSplit

DrumSplit is a local desktop-oriented drum stem separation project intended to split a drum track into individual components such as kick, snare, toms, hi-hat, cymbals, and other percussion.

## Planned workflow

1. Import a drum-only audio file.
2. Run a dedicated drum-component separation model.
3. Export isolated WAV stems.
4. Review and clean stems in Cubase, RX, or SpectraLayers.

## Initial scope

- Local processing.
- WAV/MP3 input.
- Separate output folders per job.
- Export 24-bit WAV stems.
- GPU acceleration when available.
- CPU fallback.
- No cloud upload.

## Project status

Repository initialized. Implementation will proceed in small verified stages.
